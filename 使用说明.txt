【基本信息】
  这是一个基于 AES-256-GCM 加密的图片安全查看工具。
  所有加密和解密操作都在内存中进行，不会在磁盘上留下明文痕迹。

【加密原理】
  密码 → PBKDF2(60万次迭代) → 主密钥 → HKDF(每文件随机盐) → 文件密钥 → AES-256-GCM
  每个文件使用独立的随机密钥，即使主密码相同，每个文件的加密密钥也不同。

【环境要求】
  - Python 3.9+
  - 依赖库：cryptography, Pillow, imageio

  安装依赖（仅需一次）：
  pip install -r requirements.txt

【启动方式】
  双击 run.bat 即可启动。

【首次使用】

  1. 双击 run.bat，出现密码对话框
  2. 输入一个密码（自己设定，要记住！），点击 Unlock
  3. 进入主界面后，点击菜单 File → Encrypt Images...
  4. 选择要加密的图片（支持 jpg/png/gif/webp/bmp）
  5. 选择输出文件夹，加密后的文件以 .dat 结尾
  6. 加密完成

【查看已加密图片】

  方式一：自动扫描
  1. 启动程序，输入加密时使用的密码
  2. 点击菜单 File → Open Vault...，选择存放 .dat 文件的文件夹
  3. 程序自动扫描并解密缩略图（仅内存中，不写磁盘）

  方式二：手动浏览
  1. 在 Gallery 界面点击 Browse... 选择文件夹
  2. 点击 Scan 扫描

【解密保存到磁盘】

  单张：在缩略图上右键 → Decrypt and Save As...
  批量：菜单 File → Decrypt Images... → 选择 .dat 文件 → 选择输出目录

【图片查看器操作】
  点击缩略图进入全屏查看：
  - 鼠标滚轮 + Ctrl：缩放
  - 鼠标拖拽：平移
  - 键盘 ← →：上一张 / 下一张
  - 按钮 + / -：放大缩小
  - 按钮 Fit：适应窗口

【重要注意事项】

  ⚠ 密码不会存储在程序任何位置！
  ⚠ 忘记密码 = 文件永久无法解密，无法恢复！
  ⚠ 加密后的 .dat 文件可以安全存储、传输、备份
  ⚠ 删除 .dat 文件前请确认不需要解密回原图
  ⚠ 同一个密码加密的所有文件可以一起查看（放在同一文件夹）

【文件格式】
  .dat 文件结构：[16字节文件盐] + [12字节随机数] + [AES-GCM密文+标签]
  文件名保留原始扩展名：例如 photo.jpg → photo.jpg.dat
  解密时自动还原原始文件名
